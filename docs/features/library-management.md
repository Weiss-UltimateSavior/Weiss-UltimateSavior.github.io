# 游戏库管理

游戏库是 Tyranor Next 的主要入口，负责承接目录授权、游戏扫描、识别结果展示和单游戏操作。

## 扫描结果

扫描流程会记录游戏类型、目录位置、可用引擎和最近记录。识别结果会被后续启动流程使用，避免每次启动都重新判断所有文件特征。

## 封面获取

封面能力位于应用侧功能抽象层，负责封面来源聚合与批量任务。实际封面可用性取决于来源接口、网络环境和游戏元数据质量。

## 单游戏设置

单游戏设置可覆盖默认引擎配置，适合处理特殊封包、脚本差异或需要单独调整参数的游戏。

## 文件访问

项目通过 Storage Access Framework 管理外部游戏目录，并使用 `documentFile` 辅助处理授权后的文件访问。部分原生引擎启动时仍需要真实路径映射。
