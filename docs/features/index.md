# 功能概览

Tyranor Next 围绕“识别、管理、配置、启动”四个环节组织功能。

## 游戏识别

应用会根据游戏目录中的典型文件和目录结构判断游戏类型，包括 Kirikiri、ONScripter、Artemis、TyranoBuilder、RPG Maker、Ren'Py、VN 和通用网页游戏。

## 游戏库管理

游戏库负责维护扫描结果、封面信息、最近记录和单游戏操作入口。配合 SAF 授权后，应用可以从 Android 可访问的本地存储读取游戏目录。

## 引擎启动

`EngineLauncher` 会把扫描结果映射到对应的引擎 Activity、内置 Web 运行环境或外置 APK 模块。外置模块安装后即视为可用，主 App 不维护手动启用开关。

## 配置与辅助

应用侧提供封面抓取、存档管理、在线补丁、应用级配置、引擎级配置、单游戏配置覆盖、授权和后台更新等功能抽象。
