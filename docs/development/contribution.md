# 参与贡献

欢迎参与 Tyranor Next 的开发与维护。提交 Pull Request 前，请先阅读主仓库中的贡献说明，并按项目内 `AGENT.md` 的审核方式完成提交前检查。

## 基本要求

- 遵循项目现有目录分层和代码风格。
- 避免引入与视觉小说启动器无关的冗余功能。
- 改动引擎、启动协议、文件访问和存档相关逻辑时，优先补充验证说明。
- 提交前确认构建命令和受影响功能路径。
