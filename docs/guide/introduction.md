# 项目简介

Tyranor Next 是一个面向 Android 平台的多引擎视觉小说聚合启动器，基于 Tyranor 模拟器逆向重写。

它的目标是把游戏库管理、游戏识别、引擎启动、封面获取、存档镜像和引擎参数调节放到一个轻量入口中，让玩家可以用尽量少的步骤管理和启动不同类型的 Galgame。

## 核心能力

- 管理本地存储中的视觉小说和网页式脚本游戏。
- 自动识别 Kirikiri、ONScripter、Artemis、TyranoBuilder、RPG Maker、Ren'Py 等游戏类型。
- 使用内置原生引擎、内置 Web 运行环境或外置 APK 引擎模块启动游戏。
- 为单个游戏配置引擎参数、封面信息和运行偏好。
- 管理存档镜像、KRKR 在线补丁和封面抓取流程。

## 适用场景

Tyranor Next 适合需要在 Android 设备上集中管理多类视觉小说资源的用户。它并不追求成为通用游戏中心，而是围绕视觉小说启动、识别和运行体验保持简洁。
